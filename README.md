# 🏡 House Building Guide — Pokhara 30×60

A complete interactive guide for building a family home in Pokhara, Nepal.

**Live site:** [View on GitHub Pages](https://YOUR-USERNAME.github.io/house-pokhara/)

## Features
- 📋 17 pages covering every construction phase in order
- ✅ Checklist items that save progress in your browser automatically
- 💬 Comment / notes boxes per section — saved automatically
- 📊 Progress dashboard on home page
- 🖨️ Print any page with one click
- 📱 Mobile-friendly with slide-out menu
- 🎨 Premium paint colour palette with RGB codes
- 🔬 Technical concepts explained in plain language with diagrams
